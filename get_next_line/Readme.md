# Get_next_line

## Descripcion

**`Get_next_line`** El objetivo principal de Get Next Line es programar una función en C capaz de devolver una línea leída desde un descriptor de archivo (file descriptor). Además de añadir una función muy útil a tu librería personal, este proyecto introduce el concepto fundamental de las variables estáticas en C.
